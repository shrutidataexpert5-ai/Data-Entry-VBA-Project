# Data Entry Project

An Employee Data Entry form built with Excel VBA.

## Features
- Form to enter employee details (Name, Father Name, Address, Mobile Number, Gender, Aadhar Number, Date of Birth, Email ID, PAN Number, Marital Status, Blood Group, KYC Status)
- One click saves the data into the next empty row of the Master Data sheet
- The form clears automatically after saving
- Edited a recorded macro to add logic that finds the last used row

## Tools Used
- Microsoft Excel
- VBA (Macros)

## How to Use
1. Download `Data Entry Project Template.xlsm`
2. Open the file and click **Enable Content**
3. Fill in the details in the form
4. Click the Save button. The data will be added to the Master Data sheet

This file contains no sample or real data. It is an empty template only.
